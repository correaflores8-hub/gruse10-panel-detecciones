Ventana de deduplicación

Es el control de la ventana de deduplicación — define qué tan repetida tiene que estar una detección en el tiempo para contarla como una sola.

Cómo funciona:

  1. El sistema primero agrupa las filas del archivo por el ID/IP del UAS (o, si una detección no trae ID/IP, por modelo + clasificación + zona).
  2. Dentro de cada grupo, ordena las detecciones por fecha/hora y revisa el tiempo que pasa entre una y la siguiente.
  3. Si dos detecciones del mismo UAS caen dentro de estos N minutos una de la otra, se cuentan como una sola detección real (esto es lo que resuelve el problema de que el archivo trae el mismo evento repetido varias veces — por ejemplo las variantes "remote/home/drone" o reintentos de señal).
  4. Si el mismo UAS vuelve a aparecer después de ese tiempo (por ejemplo, el mismo dron reapareciendo otro día), se cuenta como una detección aparte, no se fusiona con la anterior.

Por defecto está en 30 minutos. Si lo subes, se fusionan más detecciones entre sí (útil si tu sensor genera varias señales por el mismo vuelo en un lapso más largo); si lo bajas, se fusiona menos (útil si quieres distinguir eventos que ocurren cerca en el tiempo pero son en realidad vuelos distintos).

Este número afecta directamente el "Total único", todas las gráficas, y la tabla de "Detalle de detecciones únicas" — es la definición base de qué cuenta como "una detección" en todo el panel. Al cambiarlo, el análisis se vuelve a calcular automáticamente.
